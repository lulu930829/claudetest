# /project:review

执行项目代码审查，检查代码质量、安全性和最佳实践。

## 参数

- `--quick` 快速审查（仅检查关键问题）
- `--full` 完整审查（包括性能、安全等）
- `--path=<路径>` 审查指定路径
- `--since=<提交>` 审查指定提交以来的更改

## 工作流程

1. **代码扫描**
   - 运行ESLint检查
   - 检查TypeScript类型
   - 分析代码复杂度

2. **安全审查**
   - 检查常见安全漏洞
   - 验证敏感数据处理
   - 检查依赖安全性

3. **最佳实践检查**
   - Vue 3 Composition API使用
   - 组件设计合理性
   - 状态管理适当性

4. **测试覆盖**
   - 检查测试覆盖率
   - 验证测试质量
   - 识别缺少的测试

5. **性能分析**
   - 包体积影响
   - 渲染性能检查
   - 网络请求优化

## 输出

- 问题分类报告（高/中/低优先级）
- 具体修复建议
- 自动化修复建议（如适用）

## 示例

```bash
# 快速审查当前更改
/project:review --quick

# 完整审查src目录
/project:review --full --path=src

# 审查最近3次提交
/project:review --since=HEAD~3
```
